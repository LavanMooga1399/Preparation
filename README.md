# UPSC CSE Preparation

A personal, self-contained preparation workspace for the UPSC Civil Services Examination — GS Paper II Polity and Constitution, current affairs, and weekly mock tests. Every file is plain HTML with no build step and no dependencies, so it opens the same way on a laptop, a phone or from a repository.

## How the notes are built

Each note is a single HTML file with tabbed sections, and carries the same layers:

- **Concept explanation** written for a first reading, not a revision skim
- **A deep-reference layer** — case law with holdings, schemes mapped to Articles, exact numbers and dates
- **Prelims questions** in full exam layout, with answers hidden until an option is chosen
- **Mains answers** written to a strict word budget, each showing what was cut and what it bought
- **A last-mile revision sheet** that fits one screen

Current-affairs topic cards carry three zones: **Prelims** facts, the **static hook** a linkage question rides on, and the **Mains** argument with pros, cons and a way forward.

## The method files

Everything is written against four documents in `AI_KNOWLEDGE_BASE/`:

- **`TEST_INTELLIGENCE.md`** — the test-maker's question DNA, measured from real papers, plus the personal error patterns each note is built to counter
- **`MAINS_ANSWER_CRAFT.md`** — how a 250-word answer earns marks, including the rule that value addition is *substitution under a fixed budget*, never accumulation
- **`CURRENT_AFFAIRS_METHOD.md`** — what UPSC actually asks from current affairs, and why weeks run Sunday to Saturday
- **`NOTE_GENERATION_WORKFLOW.md`** — the build and verification process

## Two working principles

**Sourcing.** Facts are checked against primary sources — PIB press releases cited by PRID and date, PRS Legislative Research, the bare Constitution. Where a figure cannot be traced to a primary release, it is either flagged as unverified or removed. A number that cannot be sourced is deleted, not softened.

**Coverage.** A wrong answer should trace to not remembering, never to a fact missing from the notes or a concept explained badly. Every weekly test is analysed afterwards, and anything the paper asked that the notes lacked is patched back in.

## Reading progress

The dashboard tracks which notes you've read using browser storage, so it is per-device. Use **Export reading progress (JSON)** on one device and **Import** on another to carry it across.
